# Nour Candle Studio — API Documentation

## Overview

The Nour Candle Studio Order API allows clients to create, retrieve, update, and delete customer orders.

The API is implemented using Next.js Route Handlers and TypeScript. Orders are stored in an in-memory array on the server, so the data is temporary and may be lost when the server restarts.

## Order Data Model

Field Type Rule
id string Generated by the server; cannot be edited
customerName string Required, trimmed, not blank
phone string Required, trimmed, not blank; keep it as text
productName string Required, trimmed, not blank
quantity number Positive integer, minimum 1
unitPrice number Finite number, minimum 0, maximum two decimal places
total number Calculated by the server
status string One of the three supported statuses

The total is calculated as: `total = quantity × unitPrice`

New orders receive a server-generated ID, a calculated total, and an initial status of `pending`.

## Endpoints

### 1. Get All Orders

**Endpoint:** `/api/orders`

**Method:** `GET`

**Description:** Returns all orders currently stored in memory.

**Success Response:** `200 OK`

**Response Body:**

Returns an array of order objects. If there are no orders, it returns an empty array.

Example:

```json
[
  {
    "id": "order-001",
    "customerName": "Maya Haddad",
    "phone": "DEMO-001",
    "productName": "Vanilla Candle",
    "quantity": 2,
    "unitPrice": 8,
    "total": 16,
    "status": "pending"
  }
]
```

### 2. Get Order by ID

**Endpoint:** `/api/orders/[id]`

**Method:** `GET`

**Description:** Returns the order matching the provided ID.

**Success Response:** `200 OK`

Example request:

`GET /api/orders/order-001`

Example response:

```json
{
  "id": "order-001",
  "customerName": "Maya Haddad",
  "phone": "DEMO-001",
  "productName": "Vanilla Candle",
  "quantity": 2,
  "unitPrice": 8,
  "total": 16,
  "status": "pending"
}
```

**Error Response:** `404 Not Found`

Returned when no order matches the provided ID.

Example:

```json
{
  "error": "Order not found"
}
```

### 3. Create an Order

**Endpoint:** `/api/orders`

**Method:** `POST`

**Description:** Validates the submitted order details and creates a new order.

**Request Body:** JSON

Example:

```json
{
  "customerName": "Adam Al Ferekh",
  "phone": "70123456",
  "productName": "Vanilla Candle",
  "quantity": 2,
  "unitPrice": 8
}
```

**Success Response:** `201 Created`

The response contains the newly created order, including its server-generated ID, calculated total, and initial status of `pending`.

Example:

```json
{
  "id": "generated-by-server",
  "customerName": "Adam Al Ferekh",
  "phone": "70123456",
  "productName": "Vanilla Candle",
  "quantity": 2,
  "unitPrice": 8,
  "total": 16,
  "status": "pending"
}
```

**Validation Rules:**

- `customerName`, `phone`, and `productName` must be non-empty strings.
- `quantity` must be a positive integer.
- `unitPrice` must be a finite, non-negative number with at most two decimal places.
- The request body must be a valid JSON object.
- The client cannot override the server-generated ID, total, or initial status.

**Error Response:** `400 Bad Request`

Returned when the JSON is malformed or the supplied order details fail validation. The response includes an `error` message explaining the problem.

### 4. Update an Order

**Endpoint:** `/api/orders/[id]`

**Method:** `PATCH`

**Description:** Updates one or more fields of an existing order.

**Request Body:** JSON containing one or more supported fields.

Example request:

```json id="1vw9vc"
{
  "quantity": 3
}
```

Supported fields:

- `customerName`: non-empty string
- `phone`: non-empty string
- `productName`: non-empty string
- `quantity`: positive integer
- `unitPrice`: finite, non-negative number with at most two decimal places
- `status`: `pending`, `preparing`, or `delivered`

**Success Response:** `200 OK`

Returns the updated order. Fields omitted from the request remain unchanged. The server recalculates `total` whenever an update is processed, using the current quantity and unit price.

**Error Responses:**

- `400 Bad Request` — malformed JSON, an empty request object, invalid field values, unsupported fields, or attempts to update `id` or `total` directly.
- `404 Not Found` — no order matches the provided ID.

An invalid update does not partially modify the order.

### 5. Delete an Order

**Endpoint:** `/api/orders/[id]`

**Method:** `DELETE`

**Description:** Deletes an existing order from the in-memory store.

**Success Response:** `204 No Content`

A successful deletion returns an empty response body.

Example request:

`DELETE /api/orders/order-001`

**Error Response:** `404 Not Found`

Returned when no order matches the provided ID.

Example response:

```json id="xk5pp6"
{
  "error": "Order not found"
}
```
