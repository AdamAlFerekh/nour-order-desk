# Nour Candle Studio — Order Desk

A Next.js application for managing customer orders for **Nour Candle Studio**, a scented candle business. The project provides API endpoints to create, retrieve, update, and delete orders.

## Features

- Retrieve all orders or a specific order.
- Create orders with validated customer and product details.
- Update existing orders using partial updates.
- Delete existing orders.
- Calculate order totals on the server.
- Validate request data and return appropriate HTTP status codes.
- Track order status: `pending`, `preparing`, or `delivered`.

## Tech Stack

- Next.js App Router
- TypeScript
- REST-style API endpoints
- In-memory server-side storage

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository and enter the project directory:

```bash
git clone https://github.com/AdamAlFerekh/nour-order-desk.git
cd nour-order-desk
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/orders` | Retrieve all orders |
| GET | `/api/orders/[id]` | Retrieve an order by ID |
| POST | `/api/orders` | Create an order |
| PATCH | `/api/orders/[id]` | Update an existing order |
| DELETE | `/api/orders/[id]` | Delete an order |

For request examples, validation rules, and response formats, see [`docs/API.md`](docs/API.md).

## Order Details

Each order includes:

- `id` — generated by the server
- `customerName` — customer's name
- `phone` — customer's phone number
- `productName` — product name
- `quantity` — positive integer
- `unitPrice` — non-negative price with at most two decimal places
- `total` — calculated by the server
- `status` — `pending`, `preparing`, or `delivered`

## Data Storage Limitation

Orders are stored in an in-memory array. Data is temporary and may be lost when the server restarts. The project does not currently use persistent database storage.
